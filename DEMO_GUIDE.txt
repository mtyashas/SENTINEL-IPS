The demo is entirely self-contained. It generates 12,000 synthetic network flows,
trains all three models from scratch, and demonstrates every capability of the

--------------------------------------------------------------------------------
SECTION 1 / 10  --  Synthetic Network Flow Dataset
--------------------------------------------------------------------------------
Generates 12,000 flows:
  - 9,000 BENIGN flows  (normal background traffic)
  - 3,000 ATTACK flows  (375 flows x 8 attack classes)

Attack classes: DDoS, DoS, PortScan, BruteForce, Bot, Infiltration,
                Heartbleed, WebAttack

Each attack class has realistic feature perturbations:
  - DDoS    : high flow_packets_per_s, high syn_flag_count
  - PortScan: high RST flags, tiny packet sizes
  - Bot     : near-zero flow_iat_std (periodic beaconing)
  - Infiltration: long flow_duration, large backward data transfers

--------------------------------------------------------------------------------
SECTION 2 / 10  --  Model Training
--------------------------------------------------------------------------------
Trains all three IDS models on the synthetic dataset:

  BenchmarkIDS (binary)     -- XGBoost, 500 trees, full feature set
  BenchmarkIDS (multiclass) -- XGBoost, 8 attack classes
  LightweightIDS            -- XGBoost, 10 engineered features only

Models are saved to:
  models\benchmarkids_binary.pkl
  models\benchmarkids_multiclass.pkl
  models\lightweightids_binary.pkl
  models\benchmarkids_binary_feature_cols.pkl

SECTION 6 / 10  --  Multi-Dimensional Risk Scoring
--------------------------------------------------------------------------------
Each detected attack receives a composite risk score (0-100):

  Attack         Score  Label   Conf%  Severity%  Kill-Chain%  IP-Rep%
  Infiltration    68.8  MEDIUM   99.0     100.0        80.0       0.0
  DDoS            65.0  MEDIUM   97.0      75.0        95.0       0.0
  ZeroDay         63.2  MEDIUM   73.0     100.0        85.0       0.0
  BruteForce      43.5  LOW      88.0      50.0        30.0       0.0
  PortScan        37.8  LOW      82.0      25.0        40.0       0.0

Score formula: weighted sum of
  - ML confidence (how certain the model is)
  - Severity weight (CRITICAL=100, HIGH=75, MEDIUM=50, LOW=25)
  - Kill-chain stage (how far into the attack)
  - IP reputation (AbuseIPDB score if API key set)

  1. Register at https://www.virustotal.com
  2. Get your free API key
  3. Set environment variable:
     $env:VIRUSTOTAL_API_KEY = "your_key_here"

MaxMind GeoLite2 (faster offline geolocation):
  1. Register at https://www.maxmind.com
  2. Download GeoLite2-City.mmdb
  3. Place the file in:
     C:\Users\mtyas\OneDrive\Desktop\MAJOR_PROJECT\GeoLite2-City.mmdb

Alert channels (optional):
  $env:SLACK_WEBHOOK_URL = "https://hooks.slack.com/services/..."
  $env:ALERT_EMAIL_TO    = "security@yourorg.com"
  $env:WEBHOOK_URL       = "https://your-siem.example.com/alerts"

Without these, all 4 warnings you see are suppressed and the system degrades
gracefully -- IP rep checks use the local blacklist only, geo uses REST fallback,
and alerts are logged internally.
