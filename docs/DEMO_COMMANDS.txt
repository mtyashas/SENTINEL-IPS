WHAT TO WATCH
--------------
- Live capture window (Window 2): each detection prints a DETECTION line
  with attack type, confidence, severity, MITRE mapping, and response
  action taken — that's the main thing to point at during the demo.
- logs\sentinel.log — full persisted log, same DETECTION lines.
- threat_intel\ip_blacklist.txt — permanent blocks only; timed blocks
  (most of these) show as "Blocked ... via noop reason=..." in the log
  instead, not in this file.
